# kln's unreleased mods

Built and tested Minecraft mods by **kln** that are not live on Modrinth yet (waiting for review or for a free publish slot). Each release holds one mod jar.

**These are unreleased testing builds.** They work in my own tests, but expect rough edges.

## Install

1. Install [Fabric Loader](https://fabricmc.net/use/installer/) for **Minecraft 26.3**.
2. Install [Fabric API](https://modrinth.com/mod/fabric-api) for 26.3.
3. Download the `.jar` from the [Releases](../../releases) page.
4. Drop the jar in your `mods` folder and start the game.

Most of these mods are client-side only, so no server install is needed.
